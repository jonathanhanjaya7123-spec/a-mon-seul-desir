À MON SEUL DÉSIR — UPDATED OFFLINE WEBSITE

HOW TO OPEN
1. Extract the entire ZIP into a folder.
2. Keep index.html and the assets folder together.
3. Open index.html in a current version of Chrome, Edge, or Firefox.
4. Click Play in the music player to start playback. Browsers require a user gesture before audio can begin.

DRAG THE MUSIC PLAYER
- Drag the small grip (⠿) at the left of the track title to move the player.
- On touchscreens, press and drag the grip.
- For keyboard movement, focus the grip and use the arrow keys; hold Shift for smaller movements.
- The player stays within the visible screen and remembers its last position when browser storage is available.
- Dragging the grip does not interfere with the playback controls.

UPDATES
- Added a draggable music player with mouse, touch, and keyboard support.
- Removed the equalizer and all Web Audio processing. Music plays directly through the browser's native audio element.
- The letter uses a vertical, expanding dropdown in the page flow and scrolls into view when opened.
- Kept previous/next, play/pause, stop, volume, mute, seeking, repeat modes, and shuffle.
- Added clearer audio error statuses if a file cannot be loaded or decoded.
- Kept image-load diagnostics for missing image files.

IF MUSIC IS STILL SILENT
- Make sure the browser tab and computer are not muted.
- Click Play in the page; music does not start automatically.
- Extract the ZIP first. Do not open index.html from a ZIP preview.
- Keep the assets folder beside index.html. Do not rename the MP3 files.

ASSET PATHS
The HTML references the bundled files in assets/ using paths relative to index.html.
